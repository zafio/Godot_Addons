# Godot Addons

| Addon | Version | Summary |
| --- | --- | --- |
| [Blender Transform](BlenderTransform) | 1.0 | Blender-style G / R / S transforms in the 3D editor, with axis and plane constraints, numeric input and snapping. |
| [Hover Side Panel](hover_side_panel) | 0.1 | Pops up an inspector panel beside the Scene dock when you hover a selected node. |
| [Mesh Selector](Mesh_Selector) | 1.0 | Click any mesh in the 3D viewport to select it. |
| [SuperScrubber](super_scrubber) | 1.1 | Blender-style Animation dock scrubbing: G to scrub, G or F to key, Space/F + wheel to change key values, Q/E to jump between keyframes. |
| [UV Island Animator](uv_island_animator_v1_0/addons/uv_island_animator) | 1.0.0 | Animate individual UV islands independently with AnimationPlayer. |
| [Vfov Slider](VFOV_Slider) | 2.0 | Adds a viewport toolbar slider to adjust the camera's vertical FOV. |
| [View Pie](view_pie/addons/view_pie) | 1.1.0 | Hold-Z pie menu for 3D viewport display modes and overlays; Alt+Z reverts. Requires Godot 4.6+. |
